# Data Description

## File List

| File name | Description |
| --- | --- |
| `Pantheon+SH0ES.dat` | Original Pantheon+SH0ES data |
| `Pantheon+SH0ES_STAT+SYS.cov` | Statistical and statistical+systematic covariance matrices corresponding to `Pantheon+SH0ES.dat` |
| `Pantheon+.dat` | Pantheon+ data after removing SH0ES calibration and applying a redshift cut |
| `Pantheon+_STAT+SYS.cov` | Statistical and statistical+systematic covariance matrices corresponding to `Pantheon+.dat` |
| `OHD.data` | Observational Hubble parameter data |

## Detailed Description of Each File

### `Pantheon+SH0ES.dat`

`Pantheon+SH0ES.dat` contains the nominal SN and Cepheid-host distances used in Pantheon+SH0ES. These data refer to:

- Pantheon+: arXiv:2202.04077
- SH0ES: arXiv:2112.04510

### `Pantheon+SH0ES_STAT+SYS.cov`

`Pantheon+SH0ES_STAT+SYS.cov` contains the statistical covariance matrix and the statistical+systematic covariance matrix corresponding to `Pantheon+SH0ES.dat`.

### `Pantheon+.dat`

`Pantheon+.dat` is obtained by processing `Pantheon+SH0ES.dat`. The processing includes:

- Removing the SH0ES-calibrated supernova data;
- Applying a redshift cut, keeping data with `z > 0.01`.

This file is generated by `code/Pantheon+.py`.

### `Pantheon+_STAT+SYS.cov`

`Pantheon+_STAT+SYS.cov` is the covariance matrix corresponding to `Pantheon+.dat`

### `OHD.data`

`OHD.data` contains Observational Hubble Data, taken from:

- Table 1 in arXiv:2408.02536
